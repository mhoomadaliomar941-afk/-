# ZENO | زينو — متجر إلكتروني

متجر إلكتروني عربي كامل (RTL) يعمل من **كود واحد** على:

- 🌐 **موقع إلكتروني** (كمبيوتر وجوال)
- 📱 **تطبيق أندرويد** (مجلد `android/`)
- 🍏 **تطبيق آيفون** (مجلد `ios/`)
- ⚡ **تطبيق ويب قابل للتثبيت (PWA)** — يُضاف للشاشة الرئيسية ويعمل بدون إنترنت

مبني بـ React + TypeScript + Vite، وتطبيقات الجوال عبر Capacitor.

## المزايا

**للعملاء:** واجهة رئيسية، أقسام، بحث وفلترة وترتيب، صفحة منتج (مقاسات/ألوان/مخزون/مشاركة)، سلة، مفضلة، كوبونات خصم، شحن مجاني حسب المبلغ، إتمام طلب (دفع عند الاستلام / بطاقة)، تتبّع حالة الطلب، تسجيل دخول وحساب شخصي، صفحات الشحن والاسترجاع والخصوصية والشروط.

**لوحة التحكم (`/admin`):** إحصائيات المبيعات ورسم آخر 7 أيام، الأكثر مبيعاً، تنبيه المخزون، إضافة/تعديل/حذف المنتجات مع رفع الصور، إدارة الطلبات وتغيير حالتها، الكوبونات، إعدادات المتجر (العملة، رسوم الشحن، واتساب، شريط الإعلانات).

دخول المدير الافتراضي: `admin@zeno.store` / `zeno1234` — **غيّره قبل الإطلاق.**

## التشغيل

```bash
npm install
npm run dev        # تشغيل محلي على http://localhost:5173
npm run build      # بناء نسخة الموقع في مجلد dist/
```

## النشر كموقع

ارفع مجلد `dist/` على Vercel أو Netlify أو Cloudflare Pages (ملفات إعادة التوجيه مُضمّنة).

## تطبيق أندرويد

- **تلقائياً:** كل `push` إلى GitHub يبني ملف APK عبر GitHub Actions — حمّله من تبويب **Actions ← ZENO-android-apk**.
- **يدوياً:** ثبّت Android Studio ثم: `npm run android`
- للنشر على Google Play: أنشئ نسخة موقّعة (AAB) من Android Studio: *Build ← Generate Signed Bundle*.

## تطبيق آيفون

يتطلب جهاز Mac مع Xcode:

```bash
npm run ios
```

ثم اختر فريق التطوير (Apple Developer) واضغط Run أو *Product ← Archive* للنشر على App Store.

## ⚠️ قبل الإطلاق الفعلي

حالياً تُحفظ البيانات (المنتجات، الطلبات، الحسابات) **على جهاز المستخدم نفسه**، وهذا مناسب للتجربة والعرض. لمتجر حقيقي يستقبل طلبات من عملاء متعددين تحتاج:

1. **قاعدة بيانات وخادم** (مثل Supabase أو Firebase) — كل منطق البيانات مجمّع في `src/store/StoreContext.tsx` ليسهل ربطه.
2. **بوابة دفع حقيقية** (Stripe / Moyasar / Tap / PayTabs) — الدفع بالبطاقة الآن تجريبي ولا يخصم أي مبلغ.
3. **تشفير كلمات المرور ونظام دخول آمن** عبر مزوّد المصادقة في الخادم.
4. **صور المنتجات الحقيقية** — ارفعها من لوحة التحكم (حالياً تظهر رسومات تعبيرية).

## هيكل المشروع

```
src/
  components/   الرأس، القائمة السفلية، بطاقة المنتج، الأيقونات
  pages/        الرئيسية، المتجر، المنتج، السلة، الدفع، الطلب، الحساب، المفضلة
  pages/admin/  لوحة التحكم
  store/        حالة المتجر وحفظ البيانات
  data/seed.ts  المنتجات والأقسام والإعدادات الافتراضية
android/ ios/   مشاريع تطبيقات الجوال الأصلية
```
