# Ultra Realistic Water Physics — فيزياء المياه الواقعية

مود لـ **Minecraft Java Edition 1.12.2** على **Forge 1.12.2** (مختبر على 14.23.5.2860) يستبدل طريقة انتشار الماء التقليدية بنظام سوائل فيزيائي محدود الكمية: لكل بلوك حجم ماء حقيقي باللتر، والتدفق يحدث بفعل الجاذبية والضغط الهيدروستاتيكي، والخزانات لها مستوى وضغط فعليان، والثقوب تسرّب الماء بسرعة تعتمد على حجم الثقب وارتفاع الماء (قانون تورشيلي)، والدلو ينقل 1000 لتر بالضبط مع الحفاظ على الكتلة، إضافة إلى أنابيب بأقطار مختلفة ومضخات وصمامات وتشقق/انفجار الأنابيب ومؤثرات بصرية.

> ملف المود الجاهز: **`build/libs/UltraRealisticWaterPhysics-1.12.2-1.0.0.jar`**
> تقرير الميزات: [`docs/FEATURES_REPORT.md`](docs/FEATURES_REPORT.md) — تقرير الاختبارات: [`docs/TEST_REPORT.md`](docs/TEST_REPORT.md) — ملف الإعدادات: [`config/waterphysics.cfg`](config/waterphysics.cfg)

## 1. التثبيت

1. ثبّت **Minecraft Forge 1.12.2** (الإصدار الموصى به 14.23.5.2847 أو الأحدث 14.23.5.2860؛ الحد الأدنى 14.23.5.2768).
2. انسخ الملف `UltraRealisticWaterPhysics-1.12.2-1.0.0.jar` إلى مجلد `mods` داخل مجلد اللعبة (`.minecraft/mods`) — وعلى السيرفر إلى مجلد `mods` الخاص به.
3. يجب تثبيت المود على **السيرفر وعلى كل لاعب** في اللعب الجماعي (يتحقق Forge من ذلك عند الاتصال).
4. Java 8 كما يتطلب Minecraft 1.12.2.
5. (اختياري) انسخ `config/waterphysics.cfg` إلى مجلد `config` للعبة/السيرفر، أو عدّل الإعدادات من داخل اللعبة.

**العوالم الحالية:** يعمل المود مع العوالم الموجودة. المياه الطبيعية (المحيطات والبحيرات) تبقى كما هي حتى يتم "إزعاجها" (كسر بلوك بجانبها مثلاً)، عندها تتحول الكتلة المتأثرة إلى ماء فيزيائي، وتعمل المسطحات الكبيرة كخزان لا نهائي عند مستواها (قابل للتغيير من الإعدادات). بيانات الماء تُحفظ داخل ملفات الـ chunk نفسها تحت مفتاح منفصل `WaterPhysics`، فلا تفسد بيانات Minecraft الأصلية.

**قبل إزالة المود:** استخدم `/water tovanilla x1 y1 z1 x2 y2 z2` لتحويل الماء الفيزيائي في منطقة إلى ماء عادي، وإلا سيعرض Forge تحذير البلوكات المفقودة عند فتح العالم.

## 2. الاستخدام داخل اللعبة

### الماء والدلاء
- الدلو المملوء يضع **1000 لتر** من الماء الفيزيائي، ينتشر على الأرض حسب التضاريس ويتجمع في الحفر والخزانات.
- الدلو الفارغ يأخذ **1000 لتر بالضبط** من الماء المتصل؛ إذا لم يكن هناك 1000 لتر لا يمتلئ الدلو (لا ماء من العدم).
- الموزّعات (Dispensers) تتصرف بالطريقة نفسها.

### البلوكات والأدوات (تبويب "Water Physics" في الوضع الإبداعي)
| العنصر | الوظيفة |
|---|---|
| جدار خزان مقوّى / زجاج خزان | لبناء الخزانات (أي بلوك صلب يحجز الماء أيضًا). الزجاج يُظهر مستوى الماء. |
| صنبور خزان (Spigot) | فتحة في جدار الخزان، النقر يغيّر مساحتها: 0، 5، 20، 100، 500، 2000 سم². إشارة ريدستون تغلقه. التدفق Q = Cd·A·√(2gh). |
| أنابيب نحاسية 10 / 25 / 50 سم | تنقل الماء؛ السعة لكل بلوك π·D²/4 (7.9 / 49 / 196 لتر)، المقاومة بمعادلة دارسي–وايسباخ، الضغط المسموح 1000 / 800 / 600 كيلوباسكال. |
| أنبوب زجاجي 25 سم | يُظهر الماء بداخله، ضغطه المسموح 60 كيلوباسكال فقط فينفجر عند الضغط الزائد. |
| مضخة | تسحب من الخلف وتدفع من الأمام (اتجاه الوجه عند الوضع). منحنى المضخة H(Q)=Hmax(1−(Q/Qmax)²) مع صمام عدم رجوع. النقر: تشغيل / ريدستون / إيقاف، انحناء+نقر: تدوير. |
| صمام | يُركّب على خط الأنابيب، النقر: 100/75/50/25/0 ٪، إشارة ريدستون تغلقه. |
| مقياس خزان (Tank Gauge) | جزء من جدار الخزان؛ النقر يعرض الحجم والسعة والنسبة والضغط، والمقارِن (Comparator) يقرأ نسبة الامتلاء 0–15. |
| مقياس المياه (Hydrometer) | النقر على ماء/خزان/أنبوب/مضخة/صمام يعرض: الحجم باللتر، المستوى، الضغط، سرعة التدفق، سعة الخزان؛ وأثناء حمله تظهر القراءات على الشاشة. |
| مفتاح الأنابيب | انحناء+نقر على أنبوب تالف لإصلاحه، والنقر لضبط المضخات والصمامات والصنابير. |

### ثقب الخزان
اكسر أي بلوك من جدار خزان ممتلئ: يبدأ الماء بالخروج تلقائيًا، وينخفض المستوى تدريجيًا، وتقل سرعة الخروج مع انخفاض المستوى. ثقبان = خروج أسرع تقريبًا بالضعف، والصنبور يعطي ثقوبًا صغيرة بتسرب بطيء، وإعادة وضع البلوك توقف التسرب فورًا. الثقوب المتعددة تتقاسم الماء حسب عمقها (الثقب الأعمق ضغطه أعلى).

### الأوامر (مستوى صلاحية 2)
`/water info|body|tank|region|stats|perf|add|remove|fill|clear|bucket|pipe|pipedamage|spigot|spawn|wake|tovanilla`
- `/water body x y z` — حجم الجسم المائي المتصل ومستواه وأقصى ضغط.
- `/water tank x y z` — سعة الخزان (يُحسب بطريقة "priority flood" حتى مستوى الحافة).
- `/water stats` — محاسبة الكتلة: المخزَّن = مجموع الداخل − مجموع الخارج (يجب أن يكون الانحراف ≈ 0).
- `/water perf` — عدد المناطق النشطة وزمن المحاكاة لكل tick.

## 4. البناء من المصدر

المتطلبات: JDK 8 أو أحدث (يُبنى بـ `--release 8`)، واتصال بالإنترنت في أول مرة.

```bash
./gradlew build          # Windows: gradlew.bat build
# الناتج: build/libs/UltraRealisticWaterPhysics-1.12.2-1.0.0.jar
```

ملاحظة تقنية: بيئة العمل التي بُني فيها المشروع كانت تحظر `maven.minecraftforge.net` وخوادم Mojang، لذلك لا يعتمد البناء على ForgeGradle، بل على أدوات مضمّنة في `buildSrc` تعيد تنفيذ خطوات ForgeGradle نفسها:
1. `downloadMcDeps`: تنزيل Minecraft 1.12.2 وForge 14.23.5.2860 universal وخرائط MCP `snapshot_20171003` وكل المكتبات، مع التحقق من **SHA-1** لكل ملف (من الروابط الرسمية أولًا ثم مرايا GitHub عند الفشل) — القائمة في `mcdev.json`.
2. `setupDevWorkspace`: تطبيق binpatches الخاصة بـ Forge، وفك التعمية notch→SRG→MCP، وتطبيق `forge_at.cfg` → jar للترجمة.
3. `compileJava` بإخراج Java 8.
4. `reobfJar`: إعادة التعمية MCP→SRG (اسم الحقول والدوال وقت التشغيل) مع **فحص ربط** يتأكد أن كل مرجع لـ Minecraft/Forge موجود فعلًا في مساحة الأسماء وقت التشغيل.

للاختبار على Forge حقيقي (Linux + Java 8): `./gradlew writeTestEnv` ثم `python3 tests/test_server.py` و `python3 tests/test_client.py` (يحتاج Xvfb وMesa للعميل).

## English summary

Forge 1.12.2 mod that replaces vanilla water with a finite, physically simulated fluid: per-block volumes in liters, flow driven by gravity and hydrostatic pressure (virtual-pipe model with inertia, enclosed-pressure relaxation, impact/stagnation pressure, surface-tension threshold), Torricelli leaks whose rate depends on hole area and water height, exact 1000 L buckets with mass conservation, pipes (Darcy–Weisbach), pumps (pump curve + check valve), valves, cracking/bursting pipes, tank gauges, a hydrometer HUD, chunk-based sleeping simulation, multiplayer sync and a full in-game config GUI. Install the jar from `build/libs` into `mods/` on both client and server (Forge 1.12.2 ≥ 14.23.5.2768). See `docs/FEATURES_REPORT.md` and `docs/TEST_REPORT.md`.
