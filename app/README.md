# Nazih (نزيه): mobile app

Expo SDK 58 + Expo Router + TypeScript. Arabic, right-to-left.

```bash
npm install
npx expo start          # Android / iOS / web
npm run typecheck
npx expo lint
npm run export:web      # static web build in dist/
```

- Screens: `src/app/` (IDs S01–S16 from `../replica/recon.md` are in comments).
- Data: `src/data/` — `types.ts` is the API contract; `fake.ts` is the in-memory
  version with seed data. Demo login: any Jordanian mobile number, code `123456`.
- Design tokens: `src/theme/tokens.generated.ts` is generated by
  `../replica/design/build_tokens.py`. Never edit it by hand, never use raw colours.
- Copy: `src/i18n/ar.ts`. All text is written for this app.
