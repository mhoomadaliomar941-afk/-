# REALISTIC WORLD – نسخة Java Edition 1.12.2 (Forge)

نفس المود الموجود لـ Bedrock (الطقس، المناخ، الضباب، فيزياء المياه، مركز التحكم)، منقول بالكامل لـ **Minecraft Java Edition 1.12.2** كمود **Forge**.

الملف: `release/realisticworld-1.12.2-0.3.1.jar`

## المتطلبات
- Minecraft **Java Edition 1.12.2**
- **Forge 1.12.2 – 14.23.5.2860** (آخر نسخة لـ 1.12.2، وهي اللي انجرب عليها المود)
- **Java 8** (هي المطلوبة لـ Forge 1.12.2)

## التنصيب على الكمبيوتر (لعب فردي)
1. نزّل Forge من الموقع الرسمي `files.minecraftforge.net` ← اختار **1.12.2** ← **14.23.5.2860** ← Installer.
2. شغّل الـ Installer ← **Install client**.
3. افتح مجلد اللعبة (`%appdata%\.minecraft` بويندوز) وحط ملف `realisticworld-1.12.2-0.3.1.jar` داخل مجلد `mods` (إذا ما موجود سوّيه).
4. افتح الـ Launcher واختار بروفايل **forge 1.12.2** وشغّل.
5. بقائمة **Mods** لازم يطلع **Realistic World 0.3.1**.

## على سيرفر
- حط نفس الـ jar بمجلد `mods` بالسيرفر **وبأجهزة اللاعبين** (المود يحتاج الجهتين: البلوكات والواجهة والضباب على جهاز اللاعب).
- بسجل السيرفر يطلع: `Realistic World 0.3.1 started`.

## على الهاتف (أندرويد)
هذا مود لنسخة **Java**، فما يشتغل بتطبيق Minecraft اللي على الهاتف (ذاك Bedrock، ونسخته الخاصة موجودة بمجلد `REALISTIC_WORLD/`).
لتشغيل Java على أندرويد يحتاج Launcher خاص يدعم Forge 1.12.2 (مثل PojavLauncher) وحساب Java Edition. **ما جربته على الهاتف.**

## الاستخدام
| الشي | الطريقة |
|---|---|
| **مركز التحكم** | أداة **Realistic World Control Center** (كليك يمين)، أو الأمر `/rw menu` |
| حالة المود | `/rw status` |
| الفحص الذاتي (للمشرفين) | `/rw selftest` |
| قياس خزان من الكونسول (للمشرفين) | `/rw gauge <x> <y> <z>` |
| **تشغيل منطقة بدون لاعبين** (مثل ticking area) | `/rw anchor add <x> <z>` ، `/rw anchor list` ، `/rw anchor clear` (حد أقصى 8) |

### الوصفات (Crafting Table)
| الأداة | الوصفة |
|---|---|
| Control Center | بوصلة بالنص، حديد يمين ويسار، ريدستون فوق وتحت |
| Water Gauge | بوصلة بالنص، زجاج فوق ويمين ويسار، سطل تحت |
| Water Valve | حديد، ذراع (lever)، حديد (عمودي) |
| Water Pipe ×6 | صف حديد فوق وصف حديد تحت والنص فارغ |
| Water Drain | حديد بالزوايا الأربع، قمع (hopper) بالنص |

### المياه
- **الخزان يُكتشف** لما تكسر بلوك جنب ماء ساكن (أو انفجار يكسره)، أو لما تستخدم **Water Gauge** على جدار الخزان أو جنب الماء.
- المستوى ينزل حسب قانون تورشيلي ويوقف عند أسفل الفتحة. الماء الطالع يمشي للأسفل ويتجمع بالحفر.
- **الصمام:** كليك يمين يفتحه ويسده. **الأنبوب:** يوصل خزان بخزان أو يطلع الماء برة. **المصرف:** يصرّف الماء.
- **الماء الطبيعي** (بحيرات، أنهار، بحار) ما ينلمس أبداً.
- المود **ما يبدّل إلا الهواء والماء والثلج والبرك**؛ أي بلوك وضعه اللاعب ما ينمسح (انفحص على السيرفر: 168 بلوك جدار من 168 بقت سليمة).

### الطقس
- المود يتحكم بمطر ورعد اللعبة. إذا استخدمت `/weather` يتبعه 5 دقائق ثم يرجع طبيعي.
- **الفرض** (مطر غزير، عاصفة، ضباب، موجة حر، جفاف...) من مركز التحكم ← Weather ← Force weather (للمشرفين).
- **الضباب** يتدرج على شاشتك حسب الطقس (mist, dense, rain, blizzard, haze) وما يتطبق تحت الماء.
- **الـ HUD:** من صفحة Weather (سطر الطقس) ومن صفحة Performance (سطر الأداء).

## الفرق عن نسخة Bedrock
- نفس النواة ونفس الأرقام (نفس النموذج ونفس تسلسل الأرقام العشوائية).
- **جديد بـ Java:** `/rw anchor` لتشغيل منطقة بدون لاعبين، و`/rw gauge` من الكونسول.
- الحفظ بملف `world/data/realisticworld.dat` (NBT)، واللعبة تكتبه بأمان.

## إذا شلت المود
بلوكات المود (الصمام، الأنبوب، المصرف، البرك) تنشال من العالم لأن Forge ما يعرفها بعد. Forge يسألك عند فتح العالم.
